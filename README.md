# Greek ↔ Spanish Word List Tester

A small web app for creating word lists and testing yourself on them, in either direction (Greek → Spanish or Spanish → Greek).

## Features

### Word lists (`/lists`)
- Create a list. Blank names and names already in use are rejected with a message.
- Filter lists by name. Matching ignores case and accents.
- Sort lists by name (A–Z) or by number of words (most first).
- Rename a list. The same name rules apply.
- Delete a list, after a confirmation prompt. Its words are deleted too; the dictionary and My words are not changed.

### Words in a list (`/lists/{id}`)
- **Search the dictionary** by typing a Greek or Spanish word. Matching pairs are shown with an "Add" button. The stored text uses the dictionary's spelling.
- **Add your own word** when the dictionary has no entry for it. Your text is saved as typed, and the pair is also kept in My words so it can be found by search later.
- **Edit a word in place** (Greek and Spanish). A pair that is already in the list, ignoring case and accents, is rejected.
- **Remove a word** from the list, after a confirmation prompt.

### My words (`/words`)
- Shows every word pair you have typed yourself.
- Search by Greek or Spanish text. Matching ignores case and accents.
- Edit a pair in place, or delete it after a confirmation prompt.

### Testing a list
- Start a test in either direction: Greek → Spanish or Spanish → Greek. Each list has a button for each direction.
- Words are asked one at a time, in random order, and you type the translation.
- Any accepted translation counts as correct. Missing accents and tonos are accepted, but `ñ` must be typed as `ñ` (`año` is not `ano`).
- Each answer shows whether it was right and the correct answer, then moves on.
- **Show first letter:** reveals the first letter of the expected answer. Using a hint does not change the score.
- Progress is shown as "3 of 12" with a progress bar.
- The result page shows the score and the words you missed. **Retake missed words only** starts a new test over just those words.
- A list with no words cannot be tested; its test buttons are replaced by a message.
- Test progress is kept in your browser session and is not saved to the database. If the session has expired, the app returns you to the list page.

### Dictionary (optional)
- A Greek–Spanish dictionary (FreeDict+WikDict) can be imported from a TEI file at startup, which enables the dictionary search above. See [Dictionary import](#dictionary-import).
- Without the dictionary, you can still create lists and add your own words.

### Errors
- An unknown list or page shows a "Page not found" page.
- Other errors show a generic "Something went wrong" page.
- Blank terms, blank or duplicate names, and other invalid input show a message on the page where you made the change.

## Requirements

- Java 21
- Maven

No database server is needed. The app stores its data in a file-based H2 database under `./data`, so run it from the project folder.

## Running the app

Start the app from the project folder:

```sh
mvn spring-boot:run
```

Then open <http://localhost:8080/lists>.

To build a jar and start it with the helper script (which also opens the browser):

```sh
mvn clean package
./start-repaso.sh
```

## Running the tests

```sh
mvn test
```

## Dictionary import

The dictionary file is not included in this repository. To import it, place the FreeDict Greek–Spanish TEI file in `data/dictionaries/` and start the app with the import property:

```sh
mvn spring-boot:run -Dspring-boot.run.arguments=--dictionary.import.tei=data/dictionaries/freedict-ell-spa-2023.05.29.tei
```

To keep the import setting, uncomment the `dictionary.import.tei` line in `src/main/resources/application.properties` and set it to the same path.

## Data sources

The optional Greek–Spanish dictionary is from **FreeDict+WikDict** (ell-spa, edition 2023.05.29), maintained by Karl Bartel. It is automatically generated by [WikDict](http://www.wikdict.com/) from [Wiktionary](https://www.wiktionary.org/) data via [DBnary](http://kaiko.getalp.org/about-dbnary/).
